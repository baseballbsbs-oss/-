# 공황 기록 (Panic Tracker)

공황장애를 추적관찰하기 위한 갤럭시(안드로이드) 앱입니다.
투약 · 증상 · 수면을 기록하고, 약동학 모델로 **예상 혈중 약물 농도 곡선**을 그려 줍니다.

모든 기록은 기기 안의 SQLite(Room) 에만 저장되며 서버로 나가지 않습니다.

---

## 화면 구성

하단 메뉴 5개로 이루어져 있습니다.

| 메뉴 | 하는 일 |
|---|---|
| **농도** | 약물 농도 곡선, 약효 상태, "지금 복용" 버튼, 오늘 요약 |
| **증상** | 버튼 한 번으로 증상 기록, 최근 기록 목록 |
| **수면** | 취침 / 중간에 깸 / 다시 잠듦 / 완전히 기상, 낮잠 |
| **약물** | 성분명 · 제품명 · 용량 · 약동학 값 등록 |
| **통계** | 수면 · 증상 통계 (7 / 30 / 90일) |

## 1. 약물 농도 곡선

### 모델

1-구획 · 1차 흡수(경구) 모델을 씁니다. 혈중농도는 Bateman 식을 따릅니다.

```
C(t) = (F · D · ka) / (Vd · (ka − ke)) · (e^(−ke·t) − e^(−ka·t))
```

일반 사용자는 생체이용률 F 와 분포용적 Vd 를 알 수 없으므로, 이 앱은 절대 농도(ng/mL)
대신 **상대 농도(%)** 를 씁니다 — *기준 용량 1회를 복용했을 때의 최고 농도(Cmax)를 100 %* 로
두고 그에 대한 비율로 표시합니다.

입력은 제품설명서에서 그대로 옮겨 적을 수 있는 두 값뿐입니다.

- **반감기 t½** → 소실속도상수 `ke = ln2 / t½`
- **Tmax** → 흡수속도상수 `ka` 를 `Tmax = ln(ka/ke) / (ka − ke)` 로부터 이분법으로 역산

`ka > ke` 인 해가 존재하려면 `Tmax < t½ / ln2 ≈ 1.4427 · t½` 이어야 합니다.
그보다 큰 Tmax 를 넣으면 앱이 자동으로 이 한계까지 당겨서 그립니다.

### 이전 투약이 반영되는 방식

모델이 용량에 대해 **선형**이므로, 전체 농도는 각 투약이 만드는 곡선의 단순 합
(**중첩, superposition**)입니다.

```
C_total(t) = Σ  100 × (복용량ᵢ / 기준용량) × shape(t − 투약시각ᵢ)
```

따라서 어제 먹은 약이 아직 남아 있는 상태에서 오늘 다시 먹으면 그 잔류량이 자동으로
더해집니다. 반감기가 긴 약(클로나제팜, SSRI 등)이 며칠에 걸쳐 축적되는 모습도 그대로
나타납니다. 계산에는 반감기의 10배 이내 투약만 포함합니다(그 이전은 기여분이 0.1 % 미만).

### 화면에서 보이는 것

- x축 = 시간, y축 = 상대 농도(%) — 약마다 다른 색의 곡선으로 겹쳐 그립니다
- 투약 시점 표식, "지금" 세로선, 12시간 / 24시간 / 3일 / 7일 보기 전환
- **그래프를 손가락으로 짚으면** 그 시각의 각 약물 농도를 읽어 줍니다
- 약효 상태: `발현 전 → 농도 상승 중 → 최고 농도 부근 → 농도 감소 중 → 작용 종료`
  와 함께 **발현 예상 시각 · 최고 예상 시각 · 작용 종료 예상 시각**

### ⚠️ 한계

이 곡선은 **문헌상의 평균값을 넣은 추정치**이며 실제 혈중농도가 아닙니다.

- 개인의 대사 속도(CYP 효소 다형성), 간·신기능, 나이, 체중을 반영하지 않습니다
- 병용 약물의 상호작용, 음식 영향을 반영하지 않습니다
- 활성 대사체를 따로 계산하지 않습니다 (예: 디아제팜 → 데스메틸디아제팜).
  필요하면 "실효 반감기"를 직접 넣어 근사하세요
- SSRI 처럼 혈중농도와 임상 효과의 시차가 큰 약에서는 곡선이 높다고 효과가 있는 것이
  아닙니다 (항불안 효과가 자리잡는 데 보통 2~4주)

**복용량이나 복용 시점을 이 그래프를 보고 스스로 바꾸지 마세요. 처방은 의사와 상의해
결정할 일입니다.** 이 앱은 진료 때 보여 줄 기록을 남기기 위한 도구입니다.

## 2. 증상 기록

**메뉴 → 증상 → 버튼 한 번**이면 기록이 끝납니다. 현재 시각으로 바로 저장되고,
스낵바에서 **실행취소**할 수 있습니다.

기록 가능한 증상 6가지: 불안 · 과호흡 · 식은땀 · 공황발작 · 졸림 · 가슴두근거림

- 강도(1~5) · 지속시간 · 메모는 **나중에** 목록에서 눌러 채웁니다 —
  발작 중에 입력 폼을 채우게 하지 않는 것이 이 화면의 유일한 목표입니다
- 버튼을 **길게 누르면** 처음부터 자세히 적을 수 있습니다
- **런처 아이콘을 길게 누르면** 앱을 열지 않고도 공황발작 · 불안 · 두근거림을
  바로 기록하는 바로가기가 나옵니다

## 3. 수면 기록

밤에 실제로 누를 수 있는 버튼만 큼직하게 둡니다.

```
[취침] → (밤중에) [중간에 깼어요] ⇄ [다시 잠들어요] → [완전히 기상]
```

- 낮잠도 같은 방식으로 기록합니다
- 중간에 깬 구간은 여러 번 기록할 수 있고, 깨어 있던 시간은 총 수면시간에서 빠집니다
- 잠든 시각과 수면의 질처럼 자면서는 알 수 없는 값은 **기상 직후**에 묻습니다
- 지난 날짜 기록은 직접 추가·수정할 수 있습니다

계산되는 값:

| 값 | 정의 |
|---|---|
| 잠자리에 머문 시간 | 취침 → 잠자리에서 일어난 시각 |
| 입면 시간 | 취침 → 잠든 시각 |
| 중간 각성 시간 | 깬 구간들의 합 |
| **총 수면시간** | (잠든 시각 → 완전히 깬 시각) − 중간 각성 시간 |
| **수면 효율** | 총 수면시간 ÷ 잠자리에 머문 시간 |

---

## 4. 통계

7일 / 30일 / 90일 구간으로 볼 수 있습니다.

**수면** — 평균 수면시간, 평균 수면효율, 평균 취침·기상 시각, 밤중 각성 횟수와 시간,
입면 시간, 평균 낮잠, 평균 수면의 질, 날짜별 수면시간 막대그래프(밤잠/낮잠 구분)

> 평균 취침 시각은 **원형 평균**으로 계산합니다. 23:50 과 00:10 의 평균은 산술평균으로는
> 12:00 이 나오지만 실제로는 00:00 이어야 하기 때문입니다.

**증상** — 총 횟수, 하루 평균, 공황발작 횟수, 무증상 연속 일수, 평균 강도,
종류별 횟수, **시간대별(0~23시) 히트맵**, 날짜별 횟수 막대그래프

## 기술 구성

- Kotlin · Jetpack Compose (Material 3) · Navigation Compose
- Room (SQLite) — 기기 내부 저장, 서버 전송 없음
- 그래프는 외부 차트 라이브러리 없이 Compose `Canvas` 로 직접 그립니다
- minSdk 26 (Android 8.0) / targetSdk 34 · `java.time` 은 core library desugaring 사용
- Material You 동적 색상 지원 (One UI 배경화면 색을 따라갑니다)

```
app/src/main/java/com/panictracker/app/
├── pk/              약동학 모델 (PkProfile) 과 중첩 계산기 (PkEngine)
├── data/
│   ├── entity/      Medication, DoseLog, SymptomLog, SleepLog, SleepAwakening
│   ├── dao/         Room DAO + 통계 집계 쿼리
│   ├── repo/        TrackerRepository, 수면·증상 통계 계산기
│   └── MedicationPresets.kt   자주 쓰는 약의 약동학 기본값
└── ui/              home(농도) · symptom · sleep · med · stats · common(그래프)
```

### 그래프 색

약물 구분 색 6가지는 **색각 이상에서도 구분되도록** 골랐습니다 — 모든 색 쌍이
OKLab 색차 ΔE 9.3 이상(적색맹 기준), 정상 색각 기준 16.4 이상입니다.
다크 모드에서 일부 색은 배경 대비가 3:1 에 조금 못 미치므로, 그래프에는 **항상 약 이름이
붙은 범례와 값 목록**을 함께 표시해 색만으로 계열을 구분하지 않게 했습니다.

## 빌드

Android Studio 로 열거나, 명령줄에서:

```bash
./gradlew assembleDebug          # APK 생성 → app/build/outputs/apk/debug/
./gradlew installDebug           # USB 로 연결된 갤럭시에 바로 설치
./gradlew test                   # 단위 테스트
```

Android SDK 34 가 필요합니다. `local.properties` 에 `sdk.dir` 이 잡혀 있어야 합니다
(Android Studio 로 한 번 열면 자동으로 생성됩니다).

### 테스트

`app/src/test/` 에 단위 테스트 32개가 있습니다.

- **PK 모델 16개** — ka 역산의 정확도, Tmax 에서 최고값 1.0 이 되는 정규화,
  소실상에서 반감기마다 절반이 되는지, 용량 선형성, 연속 투약의 중첩,
  약물 간 격리, 상태 판정(발현 전 / 최고 / 감소), 비현실적 Tmax 보정
- **수면 16개** — 총 수면시간·효율·입면시간 계산, 밤잠은 깬 날짜에 낮잠은 시작한 날짜에
  묶이는지, 자정을 넘는 평균 취침 시각(원형 평균), 증상 집계·시간대 분포·무증상 연속 일수
