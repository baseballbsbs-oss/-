# 파트별 업무 공유 스케줄러

회사 파트(부서) 단위로 계획예방정비 등 프로젝트 업무를 **함께 기록·공유**하기 위한 웹 앱입니다.
모바일에서 **작업오더를 스와이프**로 넘기며 일별 작업사항을 기록할 수 있고, **파트원 8명**이 동시에 사용할 수 있습니다.

## 업무 구조

```
프로젝트 (예: 한빛 2호기 28차 계획예방정비)
└─ 업무 메뉴 (개별 지정)
   ├─ [일반 업무]  OH 사전 준비 (현장 업무)
   │    └─ 하부 업무 …
   ├─ [일반 업무]  OH 패키지 준비 (오더 설계, 절차서, 위험성평가 등)
   │    └─ 하부 업무 …
   └─ [OH 작업오더]  OH 작업오더
        └─ 작업오더 (예: MFWP A 분해점검)
             · 오더번호 / 제목 / 기능위치 / FME 등급 / 유해위험요소 / 비고
             └─ 일별 작업사항 (날짜별 기록, 작성자 표시)  ← 스와이프로 오더 간 이동
```

- **업무 메뉴**는 유형을 선택해 자유롭게 추가합니다.
  - `일반 업무`: 제목·비고 중심의 하부 업무 (OH 사전 준비, OH 패키지 준비 등)
  - `OH 작업오더`: 오더번호·기능위치·FME 등급·유해위험요소 등 세부 항목 기록
- **일별 작업사항**은 모든 하부 업무/작업오더에 날짜별로 기록할 수 있으며, 작성자(파트원)가 함께 저장됩니다.
- 오더 상세 화면은 **좌우 스와이프**로 작업오더 간 이동합니다(하단 점/카운터 표시).

## 실행 방법

```bash
npm install
npm start
# 브라우저에서 http://localhost:3000
```

- 데이터는 `data/scheduler.db` (SQLite)에 저장됩니다. 서버를 재시작해도 유지됩니다.
- 포트 변경: `PORT=8080 npm start`

### 8명이 공유하려면

한 대의 서버(사내 PC·서버 또는 클라우드)에서 실행하고, 파트원들이 **같은 주소로 접속**하면 실시간으로 같은 데이터를 공유합니다.

```bash
# 예: 사내망에서 서버 IP가 192.168.0.10 인 경우
npm start
# 파트원들은 http://192.168.0.10:3000 으로 접속
```

> 처음 접속 시 상단 우측 **👤 버튼**에서 본인(파트원)을 선택하세요. 기록 시 작성자로 표시됩니다.

## 기술 스택

- 백엔드: Node.js + Express + better-sqlite3
- 프론트엔드: 단일 페이지(바닐라 JS), 모바일 우선 UI, 터치 스와이프
- 빌드 과정 없음 — `npm install` 후 바로 실행

## API 요약

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET/POST/DELETE | `/api/members` | 파트원(작성자) 관리 |
| GET/POST/DELETE | `/api/projects` | 프로젝트 |
| GET/POST | `/api/projects/:id/menus` | 업무 메뉴 (하부 업무 포함 조회) |
| PUT/DELETE | `/api/menus/:id` | 메뉴 수정/삭제 |
| POST | `/api/menus/:id/tasks` | 하부 업무/작업오더 추가 |
| PUT/DELETE | `/api/tasks/:id` | 작업오더 수정/삭제 |
| GET/POST | `/api/tasks/:id/logs` | 일별 작업사항 |
| PUT/DELETE | `/api/logs/:id` | 작업사항 수정/삭제 |
