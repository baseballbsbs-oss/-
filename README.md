# 파트별 업무 공유 스케줄러

회사 파트(부서) 단위로 계획예방정비 등 프로젝트 업무를 **함께 기록·공유**하기 위한 웹 앱입니다.
파트원들이 **각자 스마트폰**으로 인터넷을 통해 접속해, 작업오더를 **스와이프**로 넘기며 일별 작업사항을 기록합니다.
공용 비밀번호로 접근을 보호하고, **파트원 8명**이 함께 사용할 수 있습니다.

## 업무 구조

```
프로젝트 (예: 한빛 2호기 28차 계획예방정비)
└─ 업무 메뉴 (개별 지정)
   ├─ [일반 업무]  OH 사전 준비 (현장 업무)
   │    └─ 하부 업무 …
   ├─ [일반 업무]  OH 패키지 준비 (오더 설계, 절차서, 위험성평가 등)
   │    └─ 하부 업무 …
   └─ [OH 작업오더]  OH 작업오더
        └─ 작업오더 (예: MFWP A 분해점검)
             · 오더번호 / 제목 / 기능위치 / FME 등급 / 유해위험요소 / 비고
             └─ 일별 작업사항 (날짜별 기록, 작성자 표시)  ← 스와이프로 오더 간 이동
```

- **업무 메뉴**는 유형(`일반 업무` / `OH 작업오더`)을 선택해 자유롭게 추가합니다.
- **OH 작업오더**는 아래 세부 항목을 기록합니다.
  - 오더번호 · 기능위치 · 제목
  - **FME 등급**: ZONE 1·2·3 / STEP 1·2·3 (선택)
  - **품질등급**: Q / A / S (선택)
  - **품질입회**: V-INSP / KV-INSP / KPS-INSP / KPS-DOC / K-DOC2 (선택)
  - **산업안전 / 화재방호**(복수 선택): 고온/고압, 유해/위험물질, 고소작업, 분진/비산, 밀폐공간, 화재폭발, 소음지역, 중량물
    - **중량물** 선택 시 → 중량물을 **여러 개** 기입 (품명 : 무게 / 인양장구). 예) 로터 : 1t / 체인블록, 베어링 : 0.03t
  - **비계설치 여부**: 설치(Y)/미설치(N) — 설치 시 높이 입력
  - **설계자 / 감독자**
- **작업오더 검색**: OH 작업오더 메뉴 상단 검색창에서 제목·오더번호·기능위치·FME/품질등급·설계자·감독자·위험요인 등으로 즉시 필터링됩니다.
- **엑셀 일괄 등록**: OH 작업오더 메뉴의 `⬆ 엑셀로 여러 개 추가`에서 양식(.xlsx)을 내려받아 채운 뒤 업로드하면 여러 작업오더가 한 번에 등록됩니다(.xlsx/.csv 지원).
  - 필수: **제목**. 산업안전은 쉼표 구분(`고온/고압, 중량물`), 비계설치 `Y`/`N`, 중량물은 `품명:무게:인양장구` 형식에 여러 개는 `;`로 구분(`로터:1t:체인블록; 베어링:0.03t`).
- **일별 작업사항**은 날짜·작성자와 함께 **작업 계획**과 **실제 작업 사항**을 나눠 기록하고(계획 대비 실제 비교용, 실제는 나중에 채워도 됨), 당일 **취급 중량물**과 **위험요인**을 선택해 기록합니다. 오더 상세는 **좌우 스와이프**로 이동합니다.

### 일별 작업사항 정리 (표 + 엑셀)
상단 **📅** 버튼을 누르면 프로젝트의 모든 일별 작업사항을 표로 모아 봅니다
(일자·업무메뉴·작업오더·설계자·감독자·작성자·안전등급·위험요인·취급중량물·고소높이·작업내용).
상단 탭으로 **일별 / 작업오더별 / 설계자별 / 감독자별**로 묶어서 볼 수 있고, 각 그룹에 건수가 표시됩니다.
**날짜 범위 필터**(시작~끝)로 원하는 기간만 볼 수 있으며(`전체` 버튼으로 해제), 표 화면 우측 **⬇** 버튼으로 현재 선택한 기준·기간대로 **엑셀(.xlsx) 내보내기**가 됩니다.

### 일별 기록의 안전등급 자동 산정
일별 기록 시 당일 **취급 중량물**(작업오더에 등록된 목록에서 선택)과 **위험요인**(고소작업/비계, 고온·고압, 분진·비산, 밀폐공간, 화재폭발)을 고르면 **안전등급(A/B/C)이 자동 계산**되어 기록에 배지로 표시됩니다.

| 등급 | 기준 (하나라도 해당되면 상위 등급 우선) |
|---|---|
| **A** | 중량물 3t 이상 |
| **B** | 고온/고압 · 분진/비산 · 밀폐공간 · 중량물 1t 이상 3t 미만 |
| **C** | 고소작업 · 화재폭발 · 중량물 1t 미만 |

> 중량물 무게는 `1t`, `0.03t`, `500kg`(→0.5t)처럼 입력해도 자동 인식합니다. 등급은 서버에서도 다시 계산해 저장하며, CSV 내보내기에 `당일안전등급/당일위험요인/당일취급중량물/당일고소작업높이` 열로 포함됩니다.

**고소작업 높이**: 당일 위험요인에서 **고소작업**을 선택하면 높이 입력칸이 나타나며, 해당 작업오더의 **비계 높이가 기본값으로 자동 적용**됩니다. 그날 실제 높이가 다르면 **별도로 수정**해 기록할 수 있습니다.

### 동시 접근 방지 (한 번에 한 명)
여러 명이 같은 작업오더를 동시에 편집해 내용이 꼬이는 것을 막기 위해 **사용 중 잠금**이 있습니다.
- 작업오더를 열면 그 사람이 잠금을 잡고, 다른 사람에게는 목록에 **🔒 ○○ 사용중** 으로 표시되며 열리지 않습니다(안내 후 진입 차단).
- 스와이프로 다른 오더로 넘어가면 이전 오더 잠금은 풀리고 새 오더 잠금을 잡습니다.
- 브라우저를 그대로 닫아도 **약 40초 뒤 자동 해제**되어 영구 잠김을 방지합니다(사용 중에는 자동 신호로 유지).
- 서버에서도 잠금 소유자만 기록/수정하도록 이중으로 막습니다.

## 📱 스마트폰으로 공유하기 (무료 배포 가이드)

각자 휴대폰에서 쓰려면 앱을 인터넷에 올려야 합니다. **데이터는 무료 Postgres(Neon)** 에,
**앱은 무료 웹 서비스(Render)** 에 올리는 방식으로 **월 비용 0원**으로 구성할 수 있습니다.

### 1단계 — 데이터베이스 만들기 (Neon, 무료)
1. <https://neon.tech> 가입 → **New Project** 생성
2. 대시보드의 **Connection string** 복사 (형식: `postgresql://user:pass@...neon.tech/dbname?sslmode=require`)
   - 이 값이 아래 `DATABASE_URL` 입니다. 표는 앱이 처음 실행될 때 자동으로 생성됩니다.

### 2단계 — 앱 올리기 (Render, 무료)
1. 이 저장소를 본인 GitHub 계정으로 가져옵니다.
2. <https://render.com> 가입 → **New +** → **Blueprint** → 이 저장소 선택
   (저장소의 `render.yaml` 을 자동 인식합니다. 또는 **Web Service** 로 만들고 Build `npm install`, Start `npm start` 지정)
3. **환경변수(Environment)** 두 개를 입력합니다:
   | 키 | 값 |
   |---|---|
   | `DATABASE_URL` | 1단계에서 복사한 Neon 연결 문자열 |
   | `APP_PASSWORD` | 파트원끼리 공유할 **공용 비밀번호** |
   | `ADMIN_PASSWORD` | (선택) **관리자 비밀번호** — 관리자 기능을 쓰려면 설정 |
4. 배포가 끝나면 `https://앱이름.onrender.com` 주소가 나옵니다.

### 3단계 — 파트원에게 공유
- 위 주소를 8명에게 전달 → 각자 휴대폰 브라우저로 접속 → **공용 비밀번호 입력**
- 홈 화면에 추가하면 앱처럼 사용할 수 있습니다 (iOS Safari·Android Chrome 모두 지원).
- 첫 접속 시 상단 우측 **👤** 버튼에서 본인(파트원)을 선택하면 기록에 작성자로 표시됩니다.

> ⚠️ **APP_PASSWORD 를 반드시 설정하세요.** 설정하지 않으면 인증 없이 누구나 접근할 수 있습니다.
> 무료 Render 웹 서비스는 일정 시간 접속이 없으면 잠들었다가, 다음 접속 시 첫 로딩이 몇 초 걸릴 수 있습니다(데이터는 Neon에 안전하게 보관되므로 사라지지 않습니다).

## 🛡 관리자 기능

`ADMIN_PASSWORD` 를 설정하면 관리자 기능이 켜집니다. 관리자로 쓰려면 **로그아웃 후 관리자 비밀번호로 로그인**하세요.
관리자로 로그인하면 상단 👤 이름 앞에 **🛡** 표시가 붙습니다.

- **잠금 강제 해제**: 누군가 작업오더를 오래 잡고 자리를 비웠을 때, 관리자가 강제로 잠금을 풀고 진입할 수 있습니다.
  (목록에서 사용 중인 오더를 누르면 강제 진입 확인창이 뜨고, 상세 화면의 잠금 안내에도 "🛡 관리자 강제 해제" 버튼이 나옵니다.)
- **데이터 내보내기**: 👤 → 관리자 메뉴 → "📥 데이터 내보내기"로 전체 내용을 **엑셀에서 열 수 있는 CSV**로 저장(백업·보고용). 한글이 깨지지 않도록 처리되어 있습니다.

> 일반 파트원(공용 비밀번호로 로그인)에게는 위 기능이 보이지 않으며, 서버에서도 관리자만 실행되도록 막혀 있습니다.
> 관리자 비밀번호는 공용 비밀번호와 **다르게** 정하세요.

## 로컬에서 실행 (개발용)

```bash
npm install
export DATABASE_URL="postgresql://...(로컬 또는 Neon)"
export APP_PASSWORD="원하는비밀번호"   # 미설정 시 인증 없이 열림(로컬 전용)
npm start                              # http://localhost:3000
```

## 환경변수

| 변수 | 필수 | 설명 |
|---|---|---|
| `DATABASE_URL` | ✅ | Postgres 연결 문자열 (Neon 등). 로컬 주소가 아니면 자동으로 SSL 사용 |
| `APP_PASSWORD` | 권장 | 공용 로그인 비밀번호. 미설정 시 인증 비활성화(공개) |
| `ADMIN_PASSWORD` | 선택 | 관리자 비밀번호. 설정 시 관리자 기능(강제 해제·내보내기) 활성화 |
| `PORT` | | 포트 (기본 3000, Render가 자동 주입) |
| `NODE_ENV` | | `production` 시 쿠키에 Secure 속성 적용(HTTPS 전용) |

## 기술 스택

- 백엔드: Node.js + Express + Postgres(`pg`)
- 인증: 공용 비밀번호 + HttpOnly 쿠키 세션 (`auth.js`)
- 프론트엔드: 단일 페이지(바닐라 JS), 모바일 우선 UI, 터치 스와이프 — 빌드 과정 없음

## API 요약

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/session` | 인증 사용 여부/로그인 상태 |
| POST | `/api/login`, `/api/logout` | 로그인 / 로그아웃 |
| GET/POST/DELETE | `/api/members` | 파트원(작성자) 관리 |
| GET/POST/DELETE | `/api/projects` | 프로젝트 |
| GET/POST | `/api/projects/:id/menus` | 업무 메뉴 (하부 업무 포함 조회) |
| PUT/DELETE | `/api/menus/:id` | 메뉴 수정/삭제 |
| POST | `/api/menus/:id/tasks` | 하부 업무/작업오더 추가 |
| PUT/DELETE | `/api/tasks/:id` | 작업오더 수정/삭제 |
| GET/POST | `/api/tasks/:id/logs` | 일별 작업사항 |
| PUT/DELETE | `/api/logs/:id` | 작업사항 수정/삭제 |

> `/api/login`, `/api/logout`, `/api/session` 을 제외한 모든 API는 로그인(쿠키)이 필요합니다.
